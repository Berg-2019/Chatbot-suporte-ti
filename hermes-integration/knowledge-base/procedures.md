# Procedimentos de TI

## Reset de Senha

### Como resetar minha senha do sistema?

1. Acesse a tela de login
2. Clique em "Esqueci minha senha"
3. Informe seu email corporativo (seu.email@empresa.com.br)
4. Verifique sua caixa de entrada (spam também)
5. Clique no link de redefinição enviado
6. Crie uma nova senha seguindo os requisitos:
   - Mínimo 8 caracteres
   - Pelo menos 1 letra maiúscula
   - Pelo menos 1 número
   - Pelo menos 1 caractere especial

**Tempo de validade:** 90 dias

**Contato direto:** Se não receber o email em 15 minutos, ligue para TI.

## Acesso Remoto (VPN)

### Como configurar VPN para trabalhar de casa?

1. Solicite acesso via chamado no helpdesk
2. Após aprovação, receba instruções de instalação
3. Baixe o cliente VPN da empresa
4. Configure com os dados fornecidos:
   - Servidor: vpn.empresa.com.br
   - Protocolo: OpenVPN
5. Use seu login e senha corporativa
6. Após conectar, aguarde 30 segundos para estabelecer túnel

**Nota:** Não feche o programa durante pausas

## Configuração de Email

### Como configurar email no Outlook?

**Automatico (recomendado):**
1. Abra Outlook
2. Arquivo → Adicionar Conta
3. Digite seu email corporativo
4. O Outlook detectará automaticamente
5. Siga as instruções na tela

**Manual:**
- Servidor de entrada (IMAP): mail.empresa.com.br:993
- Servidor de saída (SMTP): mail.empresa.com.br:587
- Usar SSL: Sim

## Problemas de Impressão

### O que fazer quando a impressora não responde?

1. Verifique se está ligada e conectada
2. Reinicie a impressora (desligue por 10 segundos)
3. Verifique o cabo de rede ou USB
4. Tente imprimir página de teste
5. Se ainda não funcionar, reinicie o serviço de spool:
   - Pressione Win + R
   - Digite `services.msc`
   - Encontre "Print Spooler"
   - Clique com direito → Reiniciar

**Impressora de rede:** Room/Andar/Impressora (consulte sinalização local)

## Notebook Travando

### Meu notebook está muito lento, o que fazer?

1. **Reinício simples:** Segure power 5 segundos e ligue novamente
2. **Verifique memória:**
   - Ctrl + Shift + Esc → Gerenciador de Tarefas
   - Aba "Desempenho" → Verifique uso de memória
3. **Feche programas pesados:**
   - Ctrl + Shift + Esc → Processos
   - Encerre o que não estiver usando
4. **Limpeza básica:**
   - Execute CCleaner (se instalado)
   - Limpe disco (Drive C → Limpeza de Disco)
5. **Desligue e leave por 5 minutos**

**Se persistir:** Abra chamado com descrição do problema.

## Acesso a Sistemas

### Como solicitar acesso a um novo sistema?

1. Verifique se o sistema está na lista de sistemas disponíveis
2. Solicite via chamado no helpdesk especificando:
   - Sistema desejado
   - Justificativa de negócio
   - Nivel de acesso necessário
3. Acompanhe aprovação com seu gestor
4. Receba credenciais por email seguro

**Prazo médio:** 2-5 dias úteis

**Sistemas comuns:**
- GLPI (chamados)
- SAP (financeiro)
- RH Online (folha)
- CRM (vendas)
